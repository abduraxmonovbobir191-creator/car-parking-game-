# Ultra Car Simulator — Open World (Unity 6 HDRP)

GTA-scale open-world vehicle simulator: continental terrain, soft-body damage, multiplayer + voice, police, trucking, disasters, VR, track editor, photo mode, mechanical failures, pedestrians, hydrodynamics, OBD/ECU, banking & insurance.

**Engine:** Unity 6 + HDRP  
**Modules:** 1–9 complete

---

```bash
cd server && pip install -r requirements.txt && python multiplayer_server.py
```
